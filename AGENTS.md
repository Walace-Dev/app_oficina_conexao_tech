# Instruções para assistentes de programação

## Objetivo
App demonstrativo da Oficina Conexão Tech com React + Vite, Supabase/PostgreSQL e Vercel.

## Regras
- Utilizar português do Brasil nos textos da interface.
- Manter apenas um campo de input: nome.
- Sidebar e rodapé são menus com navegação mockada em estado React.
- Manter o banco com Row Level Security: visitantes só podem INSERT.
- Nunca usar service_role nem chaves sb_secret no frontend ou no GitHub.
- Preferir pequenas mudanças verificadas com npm run build.
- Não adicionar bibliotecas sem necessidade.
